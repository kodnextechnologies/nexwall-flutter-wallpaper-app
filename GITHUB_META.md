# GitHub repository metadata

## About (description)

Open-source Flutter wallpaper app using the free NexWall Wallpaper API: categories, infinite-scroll wallpaper grid, full-screen preview and "set as wallpaper" on Android. API key via --dart-define, handles rate limits (429). MIT licensed starter.
